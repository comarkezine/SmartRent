# SmartRent - Smart Rental Management System

SmartRent is a web-based rental management system designed
to improve communication, rent payment tracking, and property
management.

## Project Features

- Tenant, Landlord, Property Manager, and System Admin accounts
- Role-based authentication
- Rental property management
- Tenant complaint submission
- Rent payment tracking
- M-Pesa Daraja integration (planned)
- Predictive payment tracking using machine learning (planned)

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite (development)
- PostgreSQL (planned)

## User Roles

### Tenant
- View rental information
- Make rent payments
- Submit complaints

### Landlord
- Manage rental properties
- Monitor rent payments
- Review tenant complaints

### Property Manager
- Manage assigned properties
- Handle tenant complaints
- Monitor rental operations

### System Administrator
- Manage system users
- Manage roles and permissions
- Monitor system activities
